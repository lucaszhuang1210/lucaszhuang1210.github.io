# Lucas Zhuang · Personal portfolio

A responsive, single-page portfolio for GitHub Pages. The page uses plain HTML, CSS, and original inline SVG. It has no build step, third-party fonts, tracking, or JavaScript.

## Preview

Download and open `index.html` directly, or serve this directory:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Then open http://127.0.0.1:8765. Use Tab to reach “Try aligning the signals”; Enter or Space opens the explanation and aligns the illustrated traces. The diagram uses illustrative signals, not experimental data. Open and close the example at a narrow mobile width and confirm the active section is reachable from each navigation link. Reduced-motion settings disable transitions.
